🎮 RE:WIND — Locadora de Filmes e Jogos

📌 Sobre o projeto

O RE:WIND é um projeto que desenvolvi para uma atividade da faculdade, com a proposta de criar um site de uma locadora de filmes e jogos.

A ideia foi trazer um pouco da estética retrô, lembrando as antigas locadoras, mas com um visual mais moderno, organizado e fácil de usar.

O site reúne filmes e jogos, permitindo que o usuário explore o catálogo, pesquise títulos e veja informações sobre cada produto.

🎯 Objetivo

Meu objetivo com esse projeto foi colocar em prática os conhecimentos que estou aprendendo em desenvolvimento front-end, criando um site funcional, dinâmico e com uma identidade visual própria.

💻 Tecnologias utilizadas

- HTML: para estruturar as páginas do site.
- CSS: para criar o visual, organizar os elementos e adaptar o site para diferentes telas.
- JavaScript: para adicionar interatividade e funcionalidades.

✨ Funcionalidades

- Catálogo de filmes e jogos.
- Pesquisa de títulos.
- Filtros para organizar os produtos.
- Exibição de informações dos filmes e jogos.
- Sacola com cálculo do valor.
- Formulário com validação.
- Layout responsivo.
- Elementos interativos para melhorar a navegação.

📁 Organização dos arquivos

O projeto está organizado da seguinte forma:

- "index.html" — estrutura principal do site.
- "css/" — arquivos responsáveis pela aparência do site.
- "js/" — arquivo com as funcionalidades em JavaScript.
- "assets/" — imagens e arquivos de mídia utilizados no projeto.


📚 Considerações finais

Esse projeto foi uma oportunidade de aprender mais sobre HTML, CSS e JavaScript, além de desenvolver minha criatividade na construção de uma interface.

Durante o desenvolvimento, procurei melhorar a organização dos códigos, a aparência do site e a experiência de navegação.

O RE:WIND representa um pouco da minha evolução e do que venho aprendendo na área de tecnologia.
